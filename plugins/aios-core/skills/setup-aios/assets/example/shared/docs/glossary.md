# Shared glossary

Planning terms used across Alex's workspaces. Domain-specific terms stay in their workspace glossaries.

| Term | Meaning | Notes |
|---|---|---|
| **Committed time** | Time already reserved for an agreed responsibility or activity. | Count work, travel, and preparation before adding another activity. |
| **Open action** | An agreed action whose completion has not yet been confirmed. | Record an owner and next step. A suggestion becomes an open action only after agreement. |

Follow [Maintaining vocabulary](../../.aiOS/docs/glossary.md#maintaining-vocabulary) before changing a meaning or name.
