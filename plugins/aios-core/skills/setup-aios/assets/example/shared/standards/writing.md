# Writing standard

Alex needs writing that makes the situation, evidence, and next action easy to find.

## Clarity

- Lead with the answer, decision, or current status.
- Use one name for each concept. Preserve exact file paths and identifiers.
- Prefer short sentences, concrete nouns, and active verbs.
- Use paragraphs for connected ideas, bullets for parallel points, and numbered steps for ordered actions.
- Group related information under headings. Use tables when readers need to compare the same attributes.

## Evidence

- Distinguish observed results, operator statements, assumptions, and open questions.
- Include dates and sources when facts can change.
- State uncertainty directly. Never turn a planned action into a completed result.

## Actions

- Give each agreed action an owner and a next step.
- Include a due date only when someone has agreed to it.
- State the decision Alex needs to make and the consequence of delaying it.

## Review

1. Confirm that the reader can find the outcome before the background.
2. Check names, dates, links, and claims against their sources.
3. Remove repetition and check that every action is concrete.
