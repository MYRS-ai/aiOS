# Weekly review

Turn the latest workspace reviews into an achievable plan for the coming week.

## Inputs

- The latest entries in [work](../../work/journal/AGENTS.md), [studio](../../studio/journal/AGENTS.md), and [home](../../home/journal/AGENTS.md).
- Current project, client, and household plans linked from those entries.
- The [planning constraints](../docs/planning.md), including any changes Alex reports.

## Steps

1. Read each workspace review and identify its agreed next actions and unresolved decisions.
2. Confirm which commitments changed since those reviews. Ask Alex only about missing facts that affect the plan.
3. Place agreed actions within the available time for each domain. Include recurring reviews in that time.
4. Identify conflicts and propose which actions to defer. Keep client commitments and family arrangements visible to Alex.
5. Ask Alex to resolve conflicts involving another person or a changed commitment.
6. Record the agreed priorities, deferred work, and unresolved questions in a dated shared journal entry.
7. Update changed plans in their original workspace and link them from the journal entry.

## Completion

The plan fits the agreed capacity, and every accepted action has an owner and next step.
The journal records what Alex decided. Draft messages and proposed schedule changes remain drafts until Alex authorizes them.
