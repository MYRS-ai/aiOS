# Mobile job notes acceptance

These criteria separate readiness to start the pilot from completion of the project. Passing a preliminary test does not satisfy the whole gate.

## Readiness gate

Sam records the result, date, platform, app version, and supporting evidence for each criterion. Priya reviews the technical evidence; Alex checks the operating conditions.

| Criterion | Required evidence | State at 2026-10-09 |
|---|---|---|
| Text survives interrupted connectivity | A complete note remains available until a successful send | Preliminary manual passes; confirm after the fix |
| Repeated submissions create one server note | Ten replay attempts on iOS and ten on Android, with no lost text or duplicate copies | Not met; one duplicate in the preliminary run |
| An app restart preserves unsent text | Successful restart-and-send checks on both platforms | Pending |
| Expired authentication preserves unsent text | Reauthentication followed by one complete send on both platforms | Pending |
| State labels match the actual delivery state | Checks of saved, waiting, and sent states, plus a follow-up observation | Preliminary label checks only |
| Pilot operation is agreed | Confirmed three-crew roster, response owner, and handling of unsent notes | Pending |
| Pilot evidence can be collected | Erin's review sheet and named person supplying each record | Pending |

A readiness decision must account for every row. Missing evidence cannot be treated as a pass.

## Pilot completion

The project can close when:

- The pilot has run for five working days with the agreed crews.
- Every participating crew has attempted text-note capture during at least one visit.
- No lost note or duplicate remains unresolved in the recorded pilot evidence.
- The team has reviewed the remaining usability observations and documented any deferred work.
- Alex records a wider-release or stop decision with Priya's technical assessment.
- A named support owner accepts the documented behavior and known limits.

These are completion criteria, not claims about results. The pilot has not started as of 2026-10-09.

## Explicit exclusions

This project does not promise offline support for photos, changes to dispatch assignment, or simultaneous editing by several people. A request for those behaviors requires a separate scope decision.
