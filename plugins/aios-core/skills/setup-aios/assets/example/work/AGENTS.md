# Work workspace

Alex Rivera's work as senior product manager at Fieldline, which makes scheduling software for home service businesses. Alex leads product planning for the mobile team of eight.

## Instructions

### Start with the current decision

Read [Fieldline context](context/fieldline.md), then the relevant project or routine. Use the [workspace glossary](docs/glossary.md) for product terms.

### Separate evidence from plans

Use the [working agreements](context/working-agreements.md) when reporting progress or recommending a release. A planned date does not show that work happened.

### Write for a decision

Apply the [shared writing standard](../shared/standards/writing.md). Lead with the decision needed, supporting evidence, and the next action.
