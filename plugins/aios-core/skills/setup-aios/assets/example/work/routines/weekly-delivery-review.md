# Weekly delivery review

Review the mobile team's delivery evidence and agree on the next work before the following week begins.

| Item | Arrangement |
|---|---|
| Owner | Alex Rivera |
| Participants | Alex, Priya, Sam, and the owner of any decision under review |
| Schedule | Friday, 14:00 to 14:30, in `America/Los_Angeles` |
| Execution | Alex starts the review manually; no external automation is configured |
| Last completed | [2026-10-09](../journal/2026-10-09-delivery-review.md) |
| Next planned | 2026-10-16 |

## Inputs

- The current [mobile job notes brief](../projects/mobile-job-notes/brief.md), evidence, plan, and acceptance criteria.
- The previous review's actions and any new records Alex supplies.
- Team availability for the following week, confirmed where possible.

## Run

Follow the [delivery review workflow](../workflows/delivery-review.md). Reserve the first ten minutes for changed evidence and the next fifteen for decisions. Use the final five minutes to read back owners and dates.

If the review is missed, record that it did not happen. Carry unresolved decisions forward without presenting the planned review as completed.

## Outputs

- A dated journal entry identifying evidence, decisions, unresolved questions, owners, and next review dates.
- Updated project state and planned actions, consistent with that entry.
- Work commitments for Alex's [shared weekly review](../../shared/workflows/weekly-review.md), within the [capacity plan](../../shared/docs/planning.md).
