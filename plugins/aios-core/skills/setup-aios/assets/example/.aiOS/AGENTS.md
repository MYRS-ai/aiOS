# aiOS check settings

Settings, generated product documentation, and hook results for Alex's aiOS.

## Instructions

### Configure checks

Edit `config.yaml` to change check scope or requirements. Use `aios-core:verify-aios` to inspect the resulting configuration.

### Keep documentation in its source

The plugin manages `docs/`. Change product documentation in the plugin source and personal documentation in a workspace's `docs/` folder.

### Read hook results

Read `logs/hook-events.jsonl` when investigating checks. Log entries record past runs; do not edit them.

## Contents

| Path | What it holds | Read when |
|---|---|---|
| [docs/](docs/AGENTS.md) | Product docs generated by setup or the start hook | Reading aiOS instructions |
| `logs/` | Hook event log, created when hooks run | Investigating a check result |
| [config.yaml](config.yaml) | Check settings | Changing enforcement |
