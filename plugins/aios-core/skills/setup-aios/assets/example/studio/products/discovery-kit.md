# Discovery Kit

Discovery Kit is a set of editable templates for founders investigating a product decision. It helps them connect observations to a next experiment.

**Status on October 9:** Private revision. Two independent trial readers have used the evidence worksheet. The kit has no public release date.

## Contents

| Template | Purpose | Current state |
|---|---|---|
| Discovery brief | State the decision, assumptions, and limits | Complete draft |
| Interview guide | Ask about recent behavior without proposing a solution | Complete draft |
| Evidence worksheet | Separate observations, interpretations, and remaining questions | Needs revision |
| Decision readout | Compare options and recommend the next experiment | Complete draft |

The running example concerns an invented community print workshop. It uses no Willow Labs or Fieldline material.

## Trial feedback

Two founders tried the worksheet on October 3. Both entered their own interpretations in the observation column before reading the instructions.

One reader expected a completed example beside the blank worksheet. The other could not tell whether a single interview supported a broader claim.

This feedback identifies a comprehension problem. It does not establish demand, willingness to pay, or the usefulness of the full kit.
