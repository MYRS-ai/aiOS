# Tally

Tally is a small e-ink desk display for one manually entered number and label. Its purpose is to keep a chosen measure visible without opening another app.

**Status on October 9:** Two working prototypes. The display update works over USB; enclosure durability and repeated use remain untested.

## First version

The first version would display a label such as “Pages drafted” and a number entered from a computer. It would use USB power and keep the last image when disconnected.

The first version excludes wireless connections, accounts, analytics, and automatic integrations. Alex has not committed to additional features.
