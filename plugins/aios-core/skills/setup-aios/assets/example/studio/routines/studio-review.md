# Weekly studio review

Alex reviews Rivera Studio each Thursday from 20:30 to 21:00, inside the studio's six-hour weekly allocation.

The review protects current client commitments and selects a small amount of product work. It does not require progress on every business line each week.

## Inputs

- The current [capacity plan](../context/capacity.md).
- The active [Willow Labs project](../clients/willow-labs/discovery-sprint.md).
- Current [product decisions](../products/AGENTS.md).
- The previous [studio review record](../journal/2026-10-09-studio-review.md).
- Calendar changes Alex has supplied since the last review.

## Procedure and result

Follow the [studio review workflow](../workflows/studio-review.md). Record completed work, changed evidence, decisions, and next actions in a dated journal entry.

Update current project and product docs when the review changes their state. Feed the resulting commitments into Sunday's [shared planning procedure](../../shared/workflows/weekly-review.md).
