# Studio capacity

Alex allows six hours of studio work each week. Studio work does not extend Fieldline's Monday–Friday, 09:00–17:00 working day.

These are local-time planning blocks. Alex supplies calendar changes manually; these files do not confirm availability in a calendar app.

## Regular blocks

| Block | Available time | Typical use |
|---|---|---|
| Tuesday, 19:00–21:00 | 2 hours | Client work |
| Thursday, 19:00–20:30 | 1.5 hours | Client or digital product work |
| Thursday, 20:30–21:00 | 0.5 hours | Studio review |
| Saturday, 09:00–11:00 | 2 hours | Tally testing or other focused work |

If family commitments displace a block, reduce the week's work before proposing replacement time. Do not assume evenings or weekends remain available.
