# Weekly household review

Alex and Sam agree on the next week's family commitments, meals, and household work each Sunday.

| Setting | Arrangement |
|---|---|
| Schedule | Sunday, 18:00–18:25 |
| Owner | Alex prepares the plan; Alex and Sam agree on assignments |
| Participants | Alex and Sam; ask Maya and Leo about activity needs beforehand |
| Procedure | [Plan the household week](../workflows/plan-household-week.md) |
| Latest result | [October 11 review](../journal/2026-10-11-household-review.md) |
| Next occurrence | October 18, 2026 |

## Inputs

- The current weekly plan and each adult's known commitments.
- School or activity changes reported to Alex or Sam.
- Pantry inventory, project progress, and personal goal counts.

## Outputs

- A dated weekly plan with a named adult for each pickup and activity.
- A five-dinner menu and grocery list that follow the household meal constraints.
- A journal entry separating completed work, decisions, and open actions.
- Time commitments for Alex's shared planning at 18:30.

This is a manually initiated routine. No reminder or calendar automation is connected.
If either adult cannot attend, agree on a replacement time before assigning their availability.
