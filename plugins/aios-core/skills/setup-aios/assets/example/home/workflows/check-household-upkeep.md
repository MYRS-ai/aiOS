# Check household upkeep

Produce a short record of household observations and assigned follow-up work.
The [monthly routine](../routines/monthly-household-upkeep.md) sets the schedule and owner.

## Procedure

1. Read the previous household review for unresolved maintenance actions.
2. Ask Alex to report the visible condition of the sinks, entryway, and household supplies.
3. Record each observation separately from its possible cause.
4. Turn each unresolved issue into an open action with Alex's chosen owner and due date.
5. Link work with a defined end to a household project when it needs several steps.
6. Record completed checks and follow-up actions in the next dated household review.

## Completion check

- Every item in the routine's scope has an observation or a stated reason it was not checked.
- Unchecked items remain open; missing evidence never counts as a successful inspection.
- A reported problem has an owner and a next action.
- Purchases, repair work, and service bookings remain subject to Alex's decision.

The [October 11 review](../journal/2026-10-11-household-review.md) records the latest completed check and links the entryway project.
