# Write a contract

1. Read `.aiOS/docs/types/agents-md.md` in the aiOS root for the contract definition.
2. Write or update the folder's `AGENTS.md` using that definition and the folder's actual contents.
3. Update the parent's Contents when adding or removing a folder with a contract.
4. Run the check skill from the aiOS root and resolve problems in the changed contracts.
