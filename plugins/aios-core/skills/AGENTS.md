# Core aiOS skills

These skills guide setup, checks, hook verification, and contract writing in both agent harnesses.

## Instructions

### Keep skills usable after installation

Keep each skill's instructions in its `SKILL.md`, scripts in `scripts/`, and templates in `assets/`.
Find hook code by searching upward from each script's folder.
