# File type definitions

Each file here defines one kind of file: its purpose, required fields, structure, and an example. `AGENTS.md` and `doc` files name their type in front matter. A `SKILL.md` is identified by its file name.

## Instructions

### Name each definition

Use the type's name in lowercase with hyphens. For example, `agents-md.md` defines `AGENTS.md`. Check the filename against the type it defines.
